# SNMP 테스트 툴 (CC-SNMP)

네트워크 장비의 SNMP 통신 데이터를 자동으로 수집하고 엑셀 파일로 변환·저장하는 Python 기반 테스트 도구입니다.


## 주요 기능

- SNMP 프로토콜(GET, GETSUB) 기반 네트워크 장비 데이터 수집  
- 다수 장비 일괄 처리 가능 (엑셀 파일 입력 지원)  
- 수집 결과를 엑셀 파일로 자동 저장 (오류 및 상태 메시지 포함)  
- 윈도우/리눅스별 실행 파일 빌드 지원


## 사용 언어 및 라이브러리

- Python, SQL  
- 주요 라이브러리: `pysnmp`, `pandas`, `openpyxl`, `pyinstaller` 등  


## SNMP 개요

- **GET**: 단일 OID에 대해 응답을 요청하는 통신 방식  
- **GETSUB**: 지정한 OID 하위 서브트리 전체를 대상으로 응답 요청  


## 사용 방법

1. **엑셀 파일에 장비 정보 입력**  
   IP 주소, 커뮤니티명, SNMP 타입(GET/GETSUB), OID를 작성하여 여러 장비를 한꺼번에 등록 가능  

2. **툴 실행**  
   - Windows: 실행 파일(.exe) 더블 클릭 또는 커맨드라인 실행  
   - Linux: 도커 컨테이너 내 실행 파일 실행 (환경별 빌드 필요)  

3. **결과 확인**  
   실행 후 `download` 폴더에 결과 엑셀 파일 자동 생성  


## 데이터 처리
- 수집된 SNMP 응답 데이터를 `pandas`로 가공합니다.
- 누락/오류 발생 시 상황에 맞는 메시지 삽입 (`OID 없음`, `정보 없음`, `IP 주소 없음` 등).
- `openpyxl`을 활용해 결과 엑셀 파일을 생성 및 저장합니다.

## 실행 파일 빌드
- Windows와 Linux 각각의 실행 환경에 맞게 `pyinstaller`로 별도 빌드합니다.
- Linux 빌드는 도커 컨테이너(Red Hat 기반) 내에서 진행합니다.

## 주의사항
- 프로젝트 구조 내 `file` 폴더에 장비 정보 엑셀 파일이 존재해야 합니다.
- 실행 시 결과는 `download` 폴더 내 엑셀 파일로 생성됩니다.
